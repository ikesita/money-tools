# お金の計算ツール集

税金・年金・ローン・公共料金など、暮らしのお金の「目安」をその場で計算できる無料ツール集です。すべての計算はブラウザ内で行われ、入力内容が送信されることはありません。各ツールの結果はあくまで目安で、正式な金額は公式情報でご確認ください。

## 🌐 ライブサイト

**[https://ikesita.github.io/money-tools/](https://ikesita.github.io/money-tools/)**

## 主なツール

- **ふるさと納税**：控除上限額の目安、早見表（年収別・家族構成別）
- **税金**：住民税・所得税の目安、年末調整の還付金の目安、退職金にかかる税金、医療費控除・相続税の目安、年収の壁チェッカー
- **年金・保険**：年金受給額の目安、雇用保険料、失業手当の目安
- **ローン**：住宅ローン（繰上返済シミュレーション、借入可能額の目安）、iDeCo節税シミュレーション
- **手取り**：ボーナス・月給・年収別 手取りの目安・早見表（都道府県別ボーナス、月給150,000円〜750,000円、年収300万円〜1,500万円）
- **暮らしのコスト**：電気料金の目安、車の年間維持費・自動車税、老後資金の不足額シミュレーション

## 使い方

ブラウザでライブサイトを開き、使いたいツールを選ぶだけです。インストールや会員登録は不要です。

## 注意事項

計算結果はあくまで目安です。税制や制度は変更されることがあります。正式な金額は各公式サイトや専門家にご確認ください。
